# UIDAI Hackathon – Data-Driven Aadhaar Analysis

This project analyses anonymised Aadhaar enrolment and demographic update data
to identify regional patterns, anomalies, and operational insights.

## Datasets Used
- Aadhaar Enrolment Dataset
- Aadhaar Demographic Update Dataset

## Key Insight
- Update-to-Enrolment Ratio used as an early warning indicator
- Manipur identified as a statistical outlier
- District-level drill-down enables targeted intervention

## Tools
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Outcome
The analysis demonstrates how aggregated Aadhaar data can support
proactive, data-driven decision-making.
